# Target Landing + Area Sculpting

A touch-friendly web game for target landing and area sculpting practice.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` - app markup and PWA metadata
- `styles.css` - responsive layout and visual design
- `app.js` - game logic and interactions
- `manifest.webmanifest` - installable web app manifest
- `sw.js` - service worker
- `icons/` - app icons
